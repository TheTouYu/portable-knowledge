# 复盘报告模板

顶部固定一行声明再展开：

```text
审查对象：<项目路径> + <目标任务（多会话）>
评判标准：记与忆双循环——记（结论是否沉淀到可检索载体并能被查回）· 忆（需要时是否触发通道并命中复用）· 跨项目（通用规则是否上枢纽、能否跨项目忆回）
时间范围：<起止>
```

## 任务全景

| 会话 | 时段 | 干了什么 | 阻碍 |
|---|---|---|---|
| S1 <id 前 8 位> | mm-dd HH:MM-HH:MM | ... | ... |

## ① 障碍排序（按打断程度）

| 排名 | 障碍 | 证据（时间戳/次数） | 性质 |
|---|---|---|---|
| 1 | ... | 如 29 次 400 分 3 波、中断 50 分钟 | 记忆无关 |
| 2 | ... | 如 27 次压缩后需求漂移、用户 08:53 再提醒 | 记忆漂移 |

性质四选一：`记忆命中`（复用成功）/ `记忆缺失`（规则未落盘）/ `记忆漂移`（无外部账本）/ `记忆无关`（基础设施）。

## ② 记/忆双侧断点清单

- **忆侧（想不起来）**：每条 → 断点类型（没查 / 查错方式 / 查了但载体缺 / 跨项目未接）+ 修复通道。
- **记侧（没沉淀）**：每条 → 介质缺口 + 落盘位置（技能 / 知识树 / 权威文档 / 账本 / 代码 / 提交）。
- **跨项目**：通用却没上枢纽的 → 注明上哪层（全局技能 / federation / portable-knowledge）。
- **记忆无关**（基础设施故障）：每条 → 应对经验记录点（如 collaboration-handbook A11）。

## ③ 当前障碍

被审查任务此刻卡在哪 + 遗留风险（未提交成果、未验证假设、会话仍活跃）。

## 优化落地清单

四类，每条带 trace 证据（时间点/文件位置）：

- **提示词类**：追问缺失形态、差分必查项等。
- **命令工具类**：环境预检、缺命令替代方案等。
- **技能知识类**：规则落盘、方法论章节、references 等。
- **文档类**：账本登记、权威文档更新、index 同步等。

## 继续提示词（给被审查的活跃会话）

读刚落盘的权威资料 → 当前阻碍解法规避 → 工作纪律 → 收尾清单。见 SKILL.md Phase 7。
