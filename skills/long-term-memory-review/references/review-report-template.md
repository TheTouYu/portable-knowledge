# 复盘报告模板

顶部固定一行声明再展开：

```text
审查对象：<项目路径> + <目标任务（多会话）>
评判标准：是否具备长期记忆（知识库/技能/docs 是否有答案、跨会话能否复用、结论是否落盘）
时间范围：<起止>
```

## 任务全景

| 会话 | 时段 | 干了什么 | 阻碍 |
|---|---|---|---|
| S1 <id 前 8 位> | mm-dd HH:MM-HH:MM | ... | ... |

## ① 障碍排序（按打断程度）

| 排名 | 障碍 | 证据（时间戳/次数） | 性质 |
|---|---|---|---|
| 1 | ... | 如 29 次 400 分 3 波、中断 50 分钟 | 记忆无关 |
| 2 | ... | 如 27 次压缩后需求漂移、用户 08:53 再提醒 | 记忆漂移 |

性质四选一：`记忆命中`（复用成功）/ `记忆缺失`（规则未落盘）/ `记忆漂移`（无外部账本）/ `记忆无关`（基础设施）。

## ② 记忆可解清单

- 能靠长期记忆解决：每条 → 落盘位置（技能 / 知识树 / 权威文档 / 账本）。
- 不能靠长期记忆解决：每条 → 应对经验记录点（如 collaboration-handbook A11）。

## ③ 当前障碍

被审查任务此刻卡在哪 + 遗留风险（未提交成果、未验证假设、会话仍活跃）。

## 优化落地清单

四类，每条带 trace 证据（时间点/文件位置）：

- **提示词类**：追问缺失形态、差分必查项等。
- **命令工具类**：环境预检、缺命令替代方案等。
- **技能知识类**：规则落盘、方法论章节、references 等。
- **文档类**：账本登记、权威文档更新、index 同步等。

## 继续提示词（给被审查的活跃会话）

读刚落盘的权威资料 → 当前阻碍解法规避 → 工作纪律 → 收尾清单。见 SKILL.md Phase 7。
