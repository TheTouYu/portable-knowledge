# 记忆注入可见性

记录记忆注入的可见性边界：分层准入如何决定哪些记忆能被唤醒。

### 记忆注入可见性按会话解析工作目录

按工作目录分层的记忆可见性判定必须按发起请求的会话解析工作目录，不得使用进程级共享字段；进程级单字段在并发会话下由后写者覆盖先写者，导致不同会话互相过滤对方的 project 层记忆。

#### 适用边界

只适用于按工作目录分层的记忆可见性判定；不证明任何具体记忆节点的内容正确性，也不覆盖无会话标识的后台请求——此类请求没有独立工作目录，只能按全局层放行。
